Octopus is an abstraction layer for network operations.

It keeps every network device configuration as an immutable version, detects drift from golden configurations, and runs changes as approved, auditable runbooks with rollback. Built for any organization that runs its own network.

Pre-release. Cisco IOS, IOS-XE and IOS-XR first. Built with Claude Code.
